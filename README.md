# Inoriginal Subtitle Switcher

Расширение Chrome переключает субтитры в плеере [inoriginal.cc](https://inoriginal.cc/) без открытия меню:

| Клавиша | Режим |
| --- | --- |
| `1` | Английские |
| `2` | Русские |
| `3` | Двойные |
| `4` | Выключены |

Работают также клавиши цифрового блока. Нажатия в полях ввода и сочетания с модификаторами не перехватываются. На страницах без плеера расширение ничего не делает.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `sub_switcher` с файлом `manifest.json`.
4. Обновите вкладку с фильмом.

Расширение работает только на `https://inoriginal.cc/*`. Оно не запрашивает дополнительных разрешений и не передаёт данные.
